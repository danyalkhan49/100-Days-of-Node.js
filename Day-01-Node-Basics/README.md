# 🚀 Day 1 of My Node.js Learning Journey

Started learning backend development today, and diving into Node.js was the perfect place to begin. Here's what I learned:

🔹 What is Node.js? — A runtime that lets JavaScript run outside the browser, directly on your machine. This is what makes it possible to build servers, APIs, and work with databases using JS.

🔹 node & npm — `node` runs your JavaScript files, while `npm` (Node Package Manager) lets you install and use code written by other developers, so you don't have to build everything from scratch.

🔹 package.json — Think of it as your project's ID card. It stores your project's name, version, entry point, scripts, and dependencies — created instantly with `npm init -y`.

🔹 process.argv — Learned how Node captures command-line arguments passed when running a file, like `node day1.js Ali`, and stores them in an array.

🔹 os module — Explored Node's built-in `os` module, which lets you pull system info like OS type, memory, and more — no extra installation needed.

This is just Day 1, but it already feels like a solid foundation is being built. Excited to keep going and share my progress here daily! 💻
