# LifeLink Blood Network

A blood donation and emergency blood request management platform built with Node.js, Express.js, MongoDB, and JavaScript.

## Features
- User authentication and email verification
- Donor and hospital directories
- Blood request management
- Donor offers and request tracking
- Blood compatibility support
- User profiles and notifications
- Admin management
- Responsive frontend

## Technology
- Node.js
- Express.js
- MongoDB and Mongoose
- HTML, CSS, JavaScript

## Getting Started

Install dependencies:

    npm install

Start development server:

    npm run dev

Run automated tests:

    npm test
